Open World FPS

My master's thesis project focused on open-world design using real LIDAR data processed in Houdini to simulate terrain layers. The game includes basic AI behavior trees and C++ systems for inventory and combat.

Thesis Link

Project Overview

This project was developed as part of my master’s thesis in Computer Engineering. The focus was on the procedural generation of an open-world environment using real-world LIDAR data processed through Houdini. The aim was to simulate layered terrain systems and integrate them into a functional FPS prototype using Unreal Engine 5.

Key Features:

  • LIDAR Terrain Integration: Real-world LIDAR data was used to generate the terrain, allowing for accurate elevation and landform modeling. The data was processed in Houdini to create layered geological features such as erosion channels, rainfall simulation, sediment layers, and slope-based material distribution.

  • Procedural Landscape Generation: Houdini was used to simulate terrain systems including soil erosion, slope analysis, and biome-based texturing. These layers were then imported into Unreal Engine as heightmaps and masks for dynamic material blending.

  • Dynamic Environment Effects: Material blending techniques were implemented in Unreal to create real-time weather responses like wet surfaces and snow buildup. These effects were driven by game logic and player movement to enhance immersion.

  • AI Behavior Trees: Enemy NPCs were designed using Unreal’s behavior trees and blackboard systems. AI agents patrol terrain, react to player presence, and make decisions based on sight, proximity, and state conditions.

  • Modular Gameplay Systems in C++: Built a reusable codebase for inventory, equipment, and ranged combat systems. The code followed object-oriented principles and supports easy expansion of new weapons and items.
