Project Overview

A third-person action game developed using Unreal Engine 5, focusing on combat mechanics, a large open world and immersive gameplay features.

Key Features:

  • Combat Mechanics: Multiple weapons with equip/unequip animations and distinct attack animations.

  • Advanced Animations: Utilizes root motion and Unreal Engine 5's motion wrapping for enemy and player animations. Utilized Foot IK for the player character so the feet naturally snap to different surfaces.

  • Player Abilities: Includes a dodging system and a lock-on targeting mechanism with camera focus during combat.

  • Interactive Environment: Features breakable meshes using UE5's Fracture system.

  • Collectibles: Implements pickups for coins, health, and experience points (EXP) using Niagara visual effects.
